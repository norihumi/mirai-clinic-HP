# Miraiクリニック Webサイト（架空案件）

医療機関（歯科・内科など）を想定して制作した、マルチページ対応のレスポンシブWebサイトです。

## サイトURL（GitHub Pages）
https://norihumi.github.io/mirai-clinic-hp/

## 担当範囲
* デザインカンプからのコーディング
* レスポンシブ対応（PC / スマホ）
* ハンバーガーメニュー等のJavaScript実装
* お問い合わせフォーム画面遷移

## 使用技術
* HTML5
* CSS3 (BEM設計, Flexbox, CSS Grid)
* JavaScript (ES6)

## 工夫した点・こだわり
* **BEM設計の採用**: クラス名の役割を明確にし、拡張性・保守性の高いCSS設計を行いました。
* **レスポンシブ最適化**: PC（1200px〜）とスマホ（〜768px）でデザインが崩れず、どの端末でも見やすいレイアウトを追求しました。
* **ユーザー体験（UX）**: フォームの送信完了ページ（サンクスページ）まで作成し、実務を意識した導線設計にしています。
